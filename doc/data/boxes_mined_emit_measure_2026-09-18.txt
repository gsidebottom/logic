=== What this says ===
#
# No speedup, and no cost either -- throughput is within 1.3% across all
# four runs.  The boxes are simply almost never the constraint that speaks.
#
# The scoring function was measured under the wrong distribution.  GAC
# versus UP was sampled over UNIFORM random partial assignments, and the
# search does not visit uniform random partial assignments.  A gap that
# exists is not a gap that triggers.
#
# The first explanation -- tables too WIDE to speak, since a 16-variable
# table needs most of its variables assigned while a 3-literal clause
# speaks when two literals die -- is only weakly supported.  Shrinking the
# tables 15x moved firing from 0.55% to 0.77%.
#
# The better explanation is the ADDITIVE invariant itself.  Because a mined
# box absorbs nothing, every clause it was built from is still present,
# still watched, still propagating; the box only earns its keep where the
# CONJUNCTION forces something no single clause does, and the clauses get
# there first the rest of the time.  The property that made mined boxes
# safe to add and sound to delete is the property that makes them
# redundant.  A box pays when it is the ONLY carrier of its structure --
# which means absorbing its clauses, which is what cone boxes do and why
# they cannot be deleted.
#
# The decisive follow-up, if this is pursued: emit a mined box AND remove
# the residual clauses inside its variable set.  That is sound (the table
# is exactly the models of those clauses over those variables, so the box
# entails them) and it forces the search through the stronger propagator.
# It also gives up deletability and makes the mining correctness-critical,
# which is the whole trade.
#
# A second refinement worth having either way: score candidates against the
# TRAIL STATES the search actually visits, by dumping a sample of trails
# beside the conflict clauses, instead of sampling assignments uniformly.
